# Simple Calculator

A simple web-based calculator built using **HTML, CSS, and JavaScript**. This project provides a basic calculator interface that allows users to perform common mathematical operations directly in their web browser.

## 🌐 Live Demo

Try the calculator here:

[Simple Calculator](https://skyyxyannzz.github.io/Simple-calculator/)

## ✨ Features

- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Percentage calculation (%)
- Decimal number support
- Clear (AC) button
- Backspace functionality
- Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structures the calculator interface.
- **CSS3** – Styles the calculator layout and appearance.
- **JavaScript** – Handles calculator operations and functionality.

## 🚀 How to Use

1. Open the [Live Demo](https://skyyxyannzz.github.io/Simple-calculator/).
2. Enter numbers using the calculator buttons.
3. Select the mathematical operation you want to perform.
4. Press the equals (=) button to display the result.
5. Use the AC button to clear the calculation.

This project was created as a simple programming project to practice and improve basic web development skills using HTML, CSS, and JavaScript.
